# Árvore de Natal Missionária

Site da árvore de Natal da igreja. A pessoa sorteia uma carta, lê a vida de alguém do campo missionário e oferta via Pix ou cartão.

## Rodar

```bash
npm install
npm run dev
```

A senha da administração, nesta demonstração, é `natal2026`.

O arquivo `arvore-natal-missionaria.html` na raiz é o site inteiro em um HTML só, para abrir no navegador sem instalar nada.

O pagamento real pelo Asaas ainda não está ligado. O QR da carta é de demonstração.
